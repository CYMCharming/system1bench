Aggregate accuracy can conceal changes in the individual decisions consumed by an application. We present System1Bench as a reference-aware, paired audit of typed decision interfaces, not a single cross-domain leaderboard or an end-to-end workflow test. Fifteen historical source collections provide heterogeneous decision functions and reference types; separate frozen diagnostics use executable policies and independently sourced ContractNLI and SciFact records. On Banking77, reversing the candidate dictionary changes 38\% of Laya Multilingual decisions with no net accuracy change. In the legal diagnostic, the same intervention raises two code-scored models' reference agreement while leaving only 33/144 and 51/144 cases correct under both renderings. In a post-hoc, same-source census of 339 three-class SciFact cited pairs, Qwen's total reference agreement changes only $231\to220$ while no-information agreement falls $112\to68/130$; the 159-pair complement to an earlier balanced selection preserves the class-level loss. A factorial codebook control reveals distinct sensitivities to display order and answer-code identity in two fixed adapters. These findings motivate reporting reference agreement, correctness turnover and robust correctness together, with source provenance and interface scope attached.
