\section{Limitations and scope}
\paragraph{Reference and construct validity.}
The collection combines heterogeneous source references. Synthetic-teacher agreement, authored policy conformity and programmatic rule correctness are distinct targets. Static typed decisions do not measure interactive task completion or downstream utility. The fresh policies validate supplied-rule composition; their naturalness and Chinese realization have not received independent human adjudication. AG News and BoolQ belong to known Laya training-task families; these rows cannot establish unseen-task generalization. Other public-source training overlap is unknown.

\paragraph{Intervention and system scope.}
The local systems are fixed checkpoints with one declared adapter each. Output encodings can jointly change wording and computation, and candidate reversal changes presentation and LLM code assignments together. Findings describe these implementations rather than all decision-model or language-model architectures. Historical diagnostic selection is exploratory; the first generated cases supplied a pre-inference-frozen test of declared transformations. The held-out wording test was frozen after inspecting the first generated results but before its own inference; it tests a motivated hypothesis rather than independently discovering it. Its Chinese clauses lack independent human equivalence validation.

\paragraph{Operational scope.}
Local measurements use one shared host and fixed-batch inference, not optimized serving stacks or production arrival processes. Approximately one-hertz telemetry cannot exclude brief interference or shared memory-bandwidth effects. Hosted API version IDs and usage are observable, while server weights, tokenization, scheduling and resource allocation are not. The two timing boundaries remain separate.

\paragraph{Statistical scope.}
Matched variants are dependent and resampled together. Needle analysis has only 25 source clusters. Eight timing rounds support descriptions of these workloads, not rare-tail service guarantees. Pointwise exploratory intervals across many contrasts do not provide simultaneous paper-wide error control. Inference counts are execution totals, not independent-sample counts.
