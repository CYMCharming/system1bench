# 原版权重扩展：评测进行中

本批次固定测量 Intern-Decision-0.8B/2B、Llama-3.2-1B/3B-Instruct、
Qwen3-1.7B/8B。其中 Qwen3-8B 已在主榜，本次是独立复验与新增跨领域覆盖，
不是重复增加一个主榜模型，也不覆盖它的历史成绩。
每个模型使用与已有排行榜完全相同的 4,905 个主面板决策，
以及 1,152 个跨领域／精确概率诊断决策。未完成结果不进入正式排行榜，
此前十八模型成绩不改动。运行结束后由 `analyze.py` 验证输入绑定、
原始输出、分母和模型来源，全部完成才生成新增综合分。

## 优先使用服务器已有模型

Qwen3-8B 使用 gpu29 的已有权重；Qwen3-1.7B 从 gpu24 的已有模型复制。
这些路径的名称不是可信证明：每个分片都必须与官方仓库固定版本的
SHA-256 相同，配置和分词器也必须与对应上游文件一致。
量化、剪枝、fake-quantization 或其它权重修改版本不会混入本批次。

已检查到的本地 Llama 3-8B 是 Base 而非 Instruct。它不会被静默改名，
也不会在没有独立接口设计和披露的情况下混入指令模型对照。

## Llama：下载来源与权重身份分开说明

两台服务器的 HF 登录不等于获得每个 Meta 模型的单独访问授权。
本次官方权重下载仍返回 403，因此通过公开社区分发取得 Llama 3.2。

新增核验表明：1B 和 3B 的**全部权重分片 SHA-256 与 Meta 官方
固定版本完全相同**。这证明所测权重没有被量化、剪枝或重新训练，
并非 Unsloth 的 BNB-4bit 版本。下载来源仍如实标记为 `unsloth`；
不能因为权重一致而隐去分发来源，也不能由权重一致自动推断分词器
及配置的全部字节身份。具体记录见 [身份核验](llama_weight_identity.json)。

各模型还必须通过独立准入检查：本地分片与固定分发仓库的 LFS 哈希一致，
输入文件与该仓库的 Git/LFS 哈希一致，无量化配置，权重张量为浮点类型。
原始权重以 BF16 运算，不做低比特量化。

## 质量与速度分离

质量评测使用 gpu29 的 A100。启动时两张卡空闲；后来服务器出现其他任务，
后续仅在显存余量充分且利用率适中的卡上运行质量评测。它们不是独占卡，
日志中的质量评测耗时不是受控速度排行榜。Intern 使用官方 HF 接口和
已发布温度，当前环境存在慢内核回退；不声称复现官方最快性能。

速度排名必须另外在同一硬件、相同请求负载和明确后端条件下测量，
不能把 gpu24 A800、gpu29 A100、官方 RTX 4090 和托管 API 耗时直接混排。
