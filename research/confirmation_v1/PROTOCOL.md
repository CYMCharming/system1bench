# Fresh programmatic confirmation, v1

Protocol frozen before any inference on these cases, 2026-09-29. This is a new diagnostic experiment following exploratory analysis of historical data. It confirms only compositional rule following on supplied, executable policies.

Three policy families: refunds, access control and support routing. Each includes a priority-ordered action, an escalation predicate, and an ordinal severity rule. Every answer follows from visible state/policy/parameters; neither hidden metadata nor model-generated labels determines correctness. A separately expressed declarative oracle checks generated labels. Generator seeds 101/202/303 select 32 unique base states per family/seed (288 total), balanced by original action within each seed up to one case. Sampling rejects states with no decisive one-field action intervention. Thus this is a curated diagnostic distribution, not a representative business workload.

Each base has eight variants: original; exact same-order repeat; reversed action candidates; manually translated Chinese policy/questions/criteria; explicitly irrelevant archived-record distractors; paraphrased questions; equivalent choice encodings of the boolean and ordinal questions; and a counterfactual changing exactly one operative fact and changing the correct action. Non-counterfactual variants preserve every label. Counterfactual review/severity labels are recomputed too.

Total: 2,304 requests, 6,912 decisions per model. Evaluate the same pinned local adapters and Jev 1.13.0. Local inference seed 0, BF16 configuration as recorded by original adapters, batch 8 and complete-input audits; fresh process per checkpoint. No result is used to adjust a prompt or generator. The three generator seeds are data replications, not independent model trainings. Do not use these run times as controlled speed measurements.

Primary outcomes: per-family/per-primitive base accuracy; paired change in correctness for each intervention versus base; prediction flips relative to same-order repeats; joint counterfactual success (both original and changed action correct). Report action majority baselines and review/severity label distributions. All intervention contrasts are reported, regardless of sign. Bootstrap 10,000 times over the 96 base-state clusters within each family, seed 20260929; intervals are pointwise/descriptive across the declared finite contrast family. Report per-generator-seed values. No causal claim about architecture follows from these adapter comparisons.

External validity: structured policy interpretation, not unobserved outcomes, interactive utility or human business decisions. Chinese rendering is authored, not independently human adjudicated. Fresh random cases reduce verbatim reuse of public benchmarks but do not establish training-data decontamination.

Premeasurement generator amendments: draft one allowed repeated states and natural class imbalance. Before any inference, draft two enforced unique base facts/parameters and action stratification; the previous input/manifest are retained locally as `.premeasurement-draft` files. No observed model output informed the amendment.

## Orthogonal LLM codebook subexperiment (frozen before inference)

For the 288 original action questions, evaluate five conditions on each 8B LLM: baseline, byte-identical repeat, reversed display with label-to-code mapping fixed, reversed code assignment with display fixed, and both changes. Codebook controls use the same single-token code vocabulary and decoder. Tests assert baseline prompts match the original adapter exactly and the both-changed prompts match its ordinary reversed-candidate rendering. The two mechanisms are not separately defined for native decision heads. Total: 1,440 additional action decisions per LLM. These controls isolate presentation and code identity within these specific LLM adapters; they do not infer a difference in model architecture.

## Predeclared primary contrast family and uncertainty

Within each model/policy family, the six primary effects are: excess action discordance under reversal relative to repeat; Chinese-minus-original action correctness; distractor-minus-original action correctness; paraphrase-minus-original action correctness; choice-encoded-minus-original review correctness; and choice-encoded-minus-original severity correctness. The smallest effect singled out for practical discussion is five percentage points, fixed before inference and not a universal pass/fail boundary. Report all six effects and simultaneous 95% max-standardized-deviation bootstrap intervals within each such six-effect family, stratifying resampling by generator seed (32 base clusters per seed, 10,000 draws). There is no simultaneous coverage claim across models or task families. Zero empirical variance is explicitly marked; a degenerate bootstrap interval does not certify population invariance. Other contrasts remain descriptive pointwise estimates. Report per-seed estimates and the joint original/counterfactual action success rate.
