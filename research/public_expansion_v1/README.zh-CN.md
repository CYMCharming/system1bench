# CLINC150 / BANKING77：新增任务与准入审核

状态：官方测试集已下载、冻结和审核。2026-10-06 启动独立的 Kev-4B / Qwen3.5-4B 试跑；完整正式评测尚未完成，不写入现有排行榜。冻结来源清单的 `prepared_not_evaluated` 记录的是准备时状态，不随模型运行修改。

## 为什么加入

CLINC150 检查两个不同能力：在 150 个已知意图之间做选择，以及识别请求不在支持范围内。它有 10 个意图领域，可以分领域分析。BANKING77 的 77 个类别都属于银行服务，适合检查同一领域内相近意图的区分能力。两者分别补充“多领域与范围边界”和“单领域细分类”，不是法律、科学任务的替代品。

保留完整选择集：CLINC150 为 **151 选 1**，包括独立的 OOS（不支持的请求）选项；BANKING77 为 **77 选 1**。没有把完整意图任务改成容易得多的二选一后仍沿用原成绩。

| 任务 | 官方测试数量 | 完整选项数 | 本地核验结果 |
| --- | ---: | ---: | --- |
| CLINC150 | 5,500 | 151 | 150 类各 30 条；另有 1,000 条 OOS；无空文本、测试集内重复 |
| BANKING77 | 3,080 | 77 | 每类 40 条；无空文本；测试集内有 1 个同标签重复 |

## 已发现的问题及处理

文本重复检查采用 Unicode NFKC、大小写折叠、空白合并，保留标点。它只能识别这种标准化后的精确重复，不能排除近义改写、模型预训练污染或所有标签错误。

1. CLINC150 有 **2 条训练 / 测试文本重合，标签不一致**。测试源索引 599 为 `where_are_you_from`，训练标签为 `how_old_are_you`；索引 938 为 `user_name`，训练标签为 `what_is_your_name`。这是需要披露的标签一致性风险，不应仅描述成“干净的官方测试集”。验证 / 测试无精确重合。
2. BANKING77 有 **7 条训练 / 测试重合**，占官方测试的 0.2273%，重合标签一致。训练集还有 4 个同标签重复组，测试集有 1 个同标签重复组。
3. 完整官方测试集保持不变，方便复核。另准备一个明确标记的“去精确重合”辅助切片：去掉与训练 / 验证精确重合的测试文本，同一测试文本仅保留首个源索引。CLINC150 剩 **5,498** 条，BANKING77 剩 **3,072** 条。它不是“无预训练污染”的证明，也不能代替官方完整测试成绩。
4. StartLux 官方说明把这两个数据集列为训练来源，并声称对测试集做了过滤；InnerJev-4B 训练数据卡也列出这两个来源。因此这些模型必须显示“已知同来源训练”的标记，不能宣称它们在这两个任务上验证了完全未见过的领域。Kev-9B 当前文档称 CLINC 广度测试不用于其训练，但这不证明基础模型预训练从未见过数据；其他模型未披露的训练来源记作未知，不能默认干净。

标准化重合文本的 SHA-256、分割数量、每类计数、重复数量和冲突数量见 [audit.json](audit.json)。源文件字节哈希见 [source_receipt.json](source_receipt.json)。没有把公开测试文本重新上传到 GitHub。

## 预先冻结的试跑

正式完整评测前，准备两个独立的可复现试跑集合：

- CLINC150：每个已知意图 1 条，另取 50 条 OOS，共 **200 条**，仍然保留全部 151 个候选。
- BANKING77：每类 2 条，共 **154 条**，仍然保留全部 77 个候选。

选择按 `SHA256(20261006:source_id)` 排序，排除训练 / 验证精确重合，测试文本不重复。没有根据任何模型成绩选题。CLINC 试跑 OOS 比例为 25%，而官方测试为 18.18%；不能直接用试跑准确率与完整测试准确率混比。试跑不加入原排行榜总分。

## 指标与边界

完整意图任务建议同时报告总体准确率、宏平均 F1、每个意图的支持数；CLINC 另报告已知意图准确率、OOS 精确率 / 召回率 / F1，以及按 10 个来源领域分组的准确率。不仅报告二分类准确率：官方 CLINC 中始终选择“已知”也有 81.82% 的范围识别准确率。

另有 `clinc150_binary_ood_adaptation`：在状态里列出同一 150 意图目录，仅回答“已知 / OOS”。这是新适配任务，不是原 151 类成绩，而且复用同一 5,500 条请求，不能当作独立数据重复计入总分。可以比较直接二分类与 151 类分类导出的范围识别；运行、聚合协议尚待冻结。

现在的类别说明仅将官方名称的下划线替换为空格，不添加人工编写的提示词、训练示例或答案解释。候选顺序固定，词义与顺序效应仍需单独控制。现有通用模型适配器提供 151 个不同的单 token 候选代码；模型自己的 tokenizer 仍须通过该适配器的单 token / 唯一性验证。模型推理输出是否支持完整类别数、输入是否超过上下文限制，需要在试跑时检查，不能通过静默删选项或截断来解决。

## 复现

```text
python research/public_expansion_v1/prepare.py --download
python -m unittest tests.test_public_expansion -v
```

只使用固定版本的官方公开文件，不需要访问令牌。原始文本、完整案例、Gold-free 请求以及参考答案分开存放在 Git 忽略的 `.aris/public_expansion_v1/` 下。

- `full.frozen.json`：原始官方测试集，案例包含参考答案，仅供本地评测器使用。
- `exact_clean.frozen.json`：去精确重合辅助切片。
- `pilot.frozen.json`：已冻结的 200 / 154 条试跑。
- `*.payloads.json`：仅白名单 `state` / `questions` 推理请求，以及案例 ID；不含 gold、源标签、领域、分层信息或训练行。
- `*.references.json`：参考答案与来源元数据，不可发送给模型。

下载后重跑会校验每个原始文件的 SHA-256；若本地源字节不同，程序拒绝替换已冻结来源收据。清单记录输入、请求、代码和本地输出的哈希。原始文件按相应许可本地使用：CLINC 为 CC-BY-3.0，BANKING77 为 CC-BY-4.0；应引用原作者，二次分发仍需遵守署名等要求。

## 独立试跑执行

`run.py --model kev_4b` / `run.py --model qwen35_4b` 复用已有官方适配器和原始 BF16 权重，不下载模型。先审核全部 354 条请求的候选完整性和上下文限制，再运行推理；请求、来源清单、适配器、运行器、模型修订和权重均留存哈希。失败请求仍计入分母。GPU 为共享环境，本次不报告或比较任何延迟。

`queue_control.py` 先核验 Qwen 的 151 个独立单 token 代码和两种完整选项格式，仅在 Kev 的 354 条完成收据通过后加载 Qwen 权重。原始预测与运行日志留在 `.aris/public_expansion_v1/runs/`，不提交。完整模型运行的聚合结果须先经 `verify_run.py MODEL` 验证 DONE 收据、354 条唯一 ID 和请求哈希，才能复制发布；部分进度没有分数。
