# 从实测出发：最值得讲的不是“谁考分最高”，而是谁值得托付决定

这里把已有证据和未验证的研究设想分开。数字来自本轮 [结果报告](RESULTS.zh-CN.md)；这不是新颖性证明，也不保证这些主题此前没人研究过。

## 1. 最适合做主线：好决策必须既不乱改，也不死守

直白说：同一个问题换个排版，你不应该变卦；但是退款过期了、病人情况变了、工单变紧急了，你必须改变决定。

只测“会不会变卦”，一个永远选 A 的模型都能拿满分。我们真的看到了这个陷阱：NanoJev 的科学题换序零改答，213/339 却是稳定地答错；规则分流有 96 对正确动作必须改变，它零改答、零题对两次都对。其游戏专项训练限制了这个例子能推广的范围。

**论文问题：决策模型的‘稳’，到底是理解了规则之后的稳，还是不理解而僵住了？**

可以把评测做成两个轴，而不是一个总分：

- 不该变时：题意不变的换序、代码置换、等义改写，统计前后都对，另列前后都错。
- 应该变时：只改变一个决定性事实，统计前后都对，再单列是否改答。

这样能区分“乱变”“僵化”“正确响应”。当前已测换序、精确重复、单事实变化；更自然的等义改写、无关事实与长链状态更新还需要新实验。特别要把 Qwen 的显示顺序和答案代码独立操作，不能靠组合换序定位原因。

故事不是‘小模型坏、大模型好’，而是：**一个模型可能看起来特别稳定，却不能胜任需要更新的决定。**

## 2. 很有业务意义：升级模型，为什么可能升级了 A 业务、降级了 B 业务？

直白说：把 4B 换成 9B，退款审核变强了，工单派给谁却变弱了。不能因为一个总分更高，就默认所有部门都能无风险升级。

首轮改事实前后都答对：退款 4B→9B 提高，分流 75/96→55/96。补了不重叠的新题以后，退款是 82/96→96/96，分流是 68/96→56/96。分流下降方向重现，但六项比较保护区间触及零，仍需扩大独立样本；各发行版训练历史不同，不能解释为参数量的因果作用。

**论文问题：平均能力的增长，会不会掩盖某些业务决定的退步？**

高价值后续不是再加一个排行榜，而是做“升级审计”：按业务、正确动作的切换类型、规则优先级分别检查新旧模型，事先确定升级的允许退步范围。真正进一步判断原因，要在同训练数据 / 同训练流程的模型之间比较，或系统地改变规则语法、去掉训练相似模板；这些尚未验证。

## 3. 很有反转感：考试冠军，可能不是部署冠军

科学题只答一次：Qwen3.5 是 283/339，Kev-4B 是 274/339。要求选项换序后仍答对：Qwen 是 250/339，Kev 是 265/339。**改变考核目标，样本榜首就换了。** 差异区间仍含零或触及零，这里是现象和待验证假设，不是已经确认的泛化优势。

**论文问题：一次答对，与不同等价表达下持续答对，哪一个更接近真实应用的价值？**

可以把“用户连续换种说法问三次”“同一个合同以不同字段顺序输入”“只改输出代码”看成一次完整考验，主指标是这组等价问题是否全部答对。错误稳定和错误纠正要另列，不把‘始终不变’奖励成可靠。

必须补强 Qwen3.5 的思考 / 生成式基线，并在相同信息、明确预算下比较，否则结论只关于当前直接决策接口，不代表传统 LLM 的上限。还应在独立自然数据上确认，尤其人工核查科学 NOINFO。

## 4. 更细但可能很精彩：风险分数对了，为什么动作还是错的？

直白说：模型把工单的严重程度分对了，但仍派错部门。首轮 Kev-9B 有 25/96 个这样的状态，新题复测有 30/96。这里仅能说两个输出的正确性脱节，不能说它‘心里知道但不愿意做’。

**论文问题：测风险分数的 benchmark，会不会高估一个完整决策系统的可靠性？**

一个系统需要同时回答“做什么、要不要人复核、风险多大”。我们可以在同一状态上评测整组答案是否都对，进一步测试一个被规则证明的跨输出约束：例如某类紧急状况下允许哪些分流动作。不能把所有‘风险高且动作 X’都凭直觉标成冲突，约束必须有业务规则依据。

有一个尚未验证的方法 idea：**当多个输出违反规则约束时，优先转交复核，而不只看单个置信度。** 它是否优于简单的低置信度阈值，需要独立开发集设计路由，再在独立测试集比较风险与覆盖率；不能在这批结果上挑阈值后宣布改进。

## 我会怎样组织论文

主叙事建议围绕第 1 条：**“真正可靠的决策：该坚持时坚持，该改变时改变。”** 第 2 条提供新题复测的业务反例，第 3 条展示考核方式如何改变样本排名，第 4 条把任务输出推进到系统级审计。

最重要的下一阶段证据是：独立人工复核的自然决策对、等义变化与决定性变化的严格区分、Qwen3.5 强生成 / 思考对照，以及有明确约束的联合输出审计。只把若干已有数据集拼在一起，本身还不够成为强论文；价值应来自这一可检验的评测原则与跨领域反例。机制、新颖性与可靠部署收益都还需要单独确认。
