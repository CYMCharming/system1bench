# SciFact three-choice cited-pair census: pre-inference protocol

This post-hoc replication expands the previously frozen balanced 180-pair SciFact3 diagnostic to the **complete eligible cited-pair census** of the same official dev split. It tests sensitivity to that earlier balanced, one-claim/one-document selection; it is **not** an independent dataset, source, or external holdout. The plan in this document is fixed before inspecting any model output on the new 339-pair requests. The source profile, frozen input, manifest, independent source/request validation, and four local input-token audits have already been saved in this directory. Do not overwrite the prior `scifact3_v1` freeze or splice its predictions into the new runs.

## Reference and eligibility

The official SciFact `claims_dev.jsonl` and `corpus.jsonl` provide 300 claims and 5,183 abstract records. The official data documentation defines `cited_doc_ids` as papers cited in the source sentence, while `evidence` identifies cited papers where annotators found evidence in the abstract. Include **only** a unique `(claim_id, cited_doc_id)` pair where the cited document exists in the abstract corpus. Assign SUPPORT or CONTRADICT from a consistent evidence entry; derive NOINFO only when that explicitly cited pair lacks an evidence entry. Do not label arbitrary unannotated corpus papers as NOINFO. After de-duplicating one repeated cited ID in claim 1245, the census has **339 pairs: 138 SUPPORT, 71 CONTRADICT, 130 NOINFO**, across 300 claims and 283 documents. NOINFO means no annotated evidence in the cited abstract, not a separately adjudicated NLI judgment, a claim about the paper's full text, or proof of absence from the wider literature. Source checks in `source_profile.py`, `profile.json`, `validate.py`, and `validation.json` audit citations, evidence labels, missing documents/text, and request hashes. Upstream text and annotations retain their respective SciFact/S2ORC licenses; source text in `frozen.json` is Git-ignored.

## Frozen interventions and overlap

`prepare.py` takes **all** eligible unique pairs in numeric claim/document order. For each, it fixes the identical question, criteria, semantic label mapping, case state, and four conditions used in `research/scifact3_v1/`: `base`, `exact_repeat`, `reversed_option_order`, and `title_removed`. `exact_repeat` has byte-identical inference payload to base. Reversal changes criterion insertion order and, for code-likelihood adapters, can also change code–label assignment: it is a **joint interface perturbation**, not a pure semantic-order intervention. Title removal deletes only `state.paper_title`; the original question still mentions a paper title, creating an instruction/state mismatch. Therefore it is a frozen visible-title stressor, **not** a clean causal shortcut ablation. Claims, abstracts, labels, and their order remain unchanged. This gives **1,356 fresh requests per system**; all five systems should process the full census rather than reuse prior predictions. The 720 requests corresponding to the earlier balanced 180 pairs have been independently verified byte-identical to the old freeze.

Mark the earlier three-choice selected 180 pairs and its **159-pair complement** before inference. The complement has 78 SUPPORT, 11 CONTRADICT, and 70 NOINFO pairs, 141 claims, and 144 documents. It was not evaluated under these three-choice conditions before this census, but **37 positive complement pairs (32 SUPPORT, 5 CONTRADICT) appeared in an earlier two-choice SciFact experiment**. Accordingly, it is not unseen model data, an independent holdout, or a new domain. Claims and documents can repeat within and across these groups; the selected 180 itself has one pair per claim/document. The manifest records exact IDs and provenance hashes.

## Fixed analysis plan

Primary estimand: for the **all-339 natural cited-pair mix**, report system- and class-specific base correctness, all three paired-condition correctness, unconditional semantic prediction flips, exact-repeat flip rate, reference-correct stability (base and perturbation both correct), correction (`wrong→right`), regression (`right→wrong`), and full 3×3 confusion matrices/prediction marginals. Report invalid/missing/error outputs separately and do not silently score them as a semantic label; show both strict all-pair denominator and valid-only denominator if any occur. For the main reversal claim, give net paired accuracy change and conditional gold-class accuracy changes. Explicitly test whether the earlier NOINFO→other migration persists in the **159-pair complement**; report it separately with its own denominators rather than pooling away class proportions. Analyze the old selected-180 subset only as an internal consistency check, not another independent replication. The earlier two-choice positive-only results are non-comparable because the label space and selected pairs differ.

Use **10,000 paired cluster bootstrap resamples by claim ID** as the primary descriptive uncertainty calculation, retaining all pairs and their conditions within each sampled claim and using a fixed recorded seed. For class-specific effects, resample claims contributing that class; keep both conditions paired. Repeat by **document ID** as sensitivity because abstracts recur. If all-group and class-specific intervals differ, show both rather than hide clustering. Report 2.5/97.5 percentiles for paired percentage-point deltas and key flip proportions; note that intervals reflect clustering within this fixed dev census, not sampling uncertainty across scientific domains or independent datasets. Treat the small 11-pair complement CONTRADICT slice as unstable and do not draw strong general conclusions from it. Do not choose a figure conclusion before inspecting raw confusion/transition data.

Local CPU audits found all 1,356/1,356 requests fit complete state/prompt construction for Laya English, Laya multilingual, Llama 3.1 8B Instruct, and Qwen3 8B; details are in `input_audit.json`. A complete HTTP payload does not establish the hosted Jev service's internal tokenization. This is paired *abstract classification with the cited document supplied*, not document retrieval, evidence-span extraction, full-text checking, or an independently adjudicated three-way benchmark. The official schema is documented at <https://github.com/allenai/scifact/blob/master/doc/data.md>; license boundaries at <https://github.com/allenai/scifact/blob/master/LICENSE.md>.
